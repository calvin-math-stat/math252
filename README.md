# Math 252

These materials were used for Math 252 in Fall 2025.  MyOpenMath was used as the main course management tool.

An older version of the course is available online at https://calvin-m252-s23.netlify.app/.  Worksheets (Graphs, Probability, and Models of Computation) can be found at https://calvin-m252-s23.netlify.app/from-class.

Note: the syllabus of this course has changed from time to time.  The 2025 version included Counting and Probability, and Linear Algebra.

To use these materials, fork the repo and make edits in a local copy (or grab individual files).

If you are looking for worksheets, the newest versions are in worksheets-quarto. Older versions are in worksheets-Rmarkdown.

12.2 Variance

Variance is a measure of how variable or how “spread out” a random variable is. We will determine the variance by looking at the difference between \(X\) and \(\operatorname{E}(X)\). If this difference tends to be large, then there is more variability. If it tends to be small, there is less.

Here’s how not to do this:

  1. Let \(X\) be a any random variable. What can you say about \(\operatorname{E}(X - \operatorname{E}(X))\)? [Hint: use facts about expected value to keep this simple.]

12.2.1 Definition

To fix this problem, we need to do something the differences \(X - \operatorname{E}(X)\). We could take absolute values, but it works better to square the differences. So here is our definition of variance.

\[ \operatorname{Var}(X) = \operatorname{E}((X - \mu_X)^2) = \operatorname{E}((X - \operatorname{E}(X))^2) \]

  2. Compute the variance of a \(\textsf{Binom}(1, p)\) random variable.

  3. Compute the variance of a \(\textsf{Binom}(2, 1/2)\) random variable.

  4. Compute the variance of a \(\textsf{Binom}(2, 1/4)\) random variable.

12.2.2 Alternate notation

Just like we can denote \(\operatorname{E}(X)\) with \(\mu_X\), we have another notation for variance as well: \(\sigma_X^2\). The square root of the varaince, denoted \(\operatorname{SD}(X)\) or \(\sigma_X\), is called the standard deviation.

12.2.3 Handy short cut

\[ \operatorname{Var}(X) = \operatorname{E}(X^2) - \operatorname{E}(X)^2 \]

12.2.5 Sums and Variance

There is a sum rule for variance, but it only applies if the random variables are independent.

Two random variables are independent if and only if

\[ operatorname{p}(X = a \land Y = b) = operatorname{p}(X = a) \cdot operatorname{p}(Y = b) \mbox{ for every } a \mbox{ and } b. \]

If \(X\) and \(Y\) are independent, then

\[ \operatorname{Var}(X + Y) = \operatorname{Var}(X) + \operatorname{Var}(Y) \]

  1. If \(X\) and \(Y\) are independent, \(\operatorname{E}(X) = 10\), \(\operatorname{Var}(X) = 4\), \(\operatorname{E}(Y) = 20\), and \(\operatorname{Var}(Y) = 9\), what are the mean and variance of \(X + Y\) and \(X - Y\)?

  2. Use the sum rule for variances to compute the variance of a \(\textsf{Binom}(2, p)\) random variable.

  3. Use the sum rule for variances to compute the variance of a \(\textsf{Binom}(n, p)\) random variable.

  4. What is the sum rule for standard deviation?

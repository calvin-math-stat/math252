4 Regular Expressions and Languages

4.1 Operations on Languages

Since languages are sets, we can use set operations like \(\cup\) and \(\cap\) to create new languages. But there are some additional operations that we will use.

  • concatenation of strings: \(xy\) is the concetanation of strings \(x\) and \(y\) (\(x\) followed by \(y\))

  • concatenation of sets: \(AB = \{ xy \mid x \in A \land y \in B \}\)

  • power: \(A^0 = \emptyset\); \(A^1 = A\); \(A^{n+1} = A^n A\). (Power is iterated concatenation.)

  • Kleene star: \(\displaystyle A^* = \cup_{n = 0}^{\infty} \; A^n\)

  1. What strings belong to \(\{0, 01\}^2\)?

  2. Which of these strings belong to \(\{0, 01\}^*\)?

    1. 01001
    2. 10110
    3. 00010

  3. Which of these strings belong to \(\{101, 111, 11\}^*\)?

    1. 1010111
    2. 1011011
    3. 1110111
    4. 11110111

4.2 Regular Expressions

Regular expression are a type of shorthand notation for representing certain types of sets.

4.2.1 Syntax

A regular expression over an input alphabet \(I\) is defined recursively.

  • \(\boldsymbol{\emptyset}\) and \(\boldsymbol{\lambda}\) and regular expressions.

  • \(\boldsymbol{x}\) is a regular expression for each \(i \in I\).

  • If \(\boldsymbol{A}\) and \(\boldsymbol{B}\) are regular expressions, then

    • \(\boldsymbol{A}^*\) is a regular expression
    • \((\boldsymbol{A} \cup \boldsymbol{B})\) is a regular expression
    • \((\boldsymbol{A}\boldsymbol{B})\) is a regular expression

4.2.2 Semantics

Each regular expression represents a language as follows.

  • \(\boldsymbol{\emptyset}\) represents the empty langauge: \(\emptyset\)
  • \(\boldsymbol{\lambda}\) represents language that contains only the empty string: \(\{\lambda\}\)
  • For each \(x \in I\), \(\boldsymbol{x}\) represents the language containing only \(x\): \(\{x \}\)
  • If \(\boldsymbol{A}\) and \(\boldsymbol{B}\) are regular expressions representing languages \(A\) and \(B\), then
    • \((\boldsymbol{A}\boldsymbol{B})\) represents \(AB\)
    • \((\boldsymbol{A} \cup \boldsymbol{B})\) represents \(A \cup B\) [Note: This is often written (A|B) in programming languages.]
    • \(\boldsymbol{A}^*\) represents \(A^*\) [Note: This is often written as A* in programming languages.]
